# mouse@work — site

Pages publiques de l'app iOS **mouse@work** : assistance et politique de confidentialité, les deux
URL exigées par App Store Connect.

- `index.html` — assistance (français, anglais, espagnol)
- `privacy.html` — politique de confidentialité (français, anglais, espagnol)
- `style.css` — feuille commune

Dépôt volontairement séparé du code de l'app, qui reste privé. Servi par GitHub Pages depuis la
branche `main`, à la racine.

Les sources de ces pages vivent aussi dans `docs/` du dépôt de l'app : toute modification doit être
reportée des deux côtés, ou reprise depuis celui-ci.
